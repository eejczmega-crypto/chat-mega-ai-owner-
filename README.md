# Chat MeGa AI — Cloudflare Workers (نسخة إصلاح)

هذه النسخة مخصصة لـ **Cloudflare Workers + D1** وليست Node.js/Express. لا ترفع ملفات نسخة Express القديمة إلى Worker.

## قبل النشر — مهم
لا يمكن أن يعمل تسجيل الدخول قبل ربط قاعدة D1 وتشغيل الجداول وإضافة أسرار المالك. إذا لم تُنفّذ هذه الخطوات، ستظهر رسالة إعداد واضحة بدلاً من خطأ JSON فارغ.

## 1) أنشئ قاعدة D1
من مجلد المشروع على جهاز كمبيوتر عليه Node.js 20 أو أحدث:

```bash
npm install
npx wrangler d1 create chat-mega-db
```

سيظهر `database_id`. افتح `wrangler.toml` واستبدل:
`REPLACE_WITH_YOUR_D1_DATABASE_ID`
بالمعرّف الذي ظهر لك، مع إبقاء `database_name = "chat-mega-db"` و`binding = "DB"` كما هي.

## 2) أنشئ جداول قاعدة البيانات
```bash
npx wrangler d1 execute chat-mega-db --remote --file=./schema.sql
```

## 3) أضف أسرار المالك ومفتاح الذكاء الاصطناعي
البريد مضبوط تلقائياً في `wrangler.toml`. أضف كلمة مرور المالك ومفتاح OpenAI كأسرار (Secrets)؛ لا تضعهما داخل ملفات الموقع أو ملف ZIP:

```bash
npx wrangler secret put OWNER_PASSWORD
npx wrangler secret put OPENAI_API_KEY
```

- `OWNER_EMAIL`: مضبوط تلقائياً على `mr11mega@gmail.com` في إعدادات Worker.
- `OWNER_PASSWORD`: اختر كلمة مرور جديدة طويلة وفريدة (12 حرفاً أو أكثر). لا تستخدم كلمة المرور التي كتبتها في المحادثة لأنها أصبحت مكشوفة. تُحفظ كـ Cloudflare Secret ولا تُضمّن في الحزمة.
- `OPENAI_API_KEY`: مفتاح API الخاص بحساب OpenAI. لا ترسله في المحادثة ولا تضعه في ملفات الواجهة.

## 4) انشر النسخة
```bash
npx wrangler deploy
```

## 5) افحص الإعداد قبل تسجيل الدخول
افتح:
`https://اسم-الـ-Worker.workers.dev/api/health`

يجب أن تكون النتيجة `ok: true` وجميع الفحوصات الأساسية ناجحة. إذا ظهرت رسالة D1، راجع ربط `DB` أو نفّذ `schema.sql`. إذا ظهرت رسالة الأسرار، أعد إضافة أسرار المالك.

بعد نجاح الفحص افتح رابط Worker الرئيسي، اختر **إنشاء حساب جديد** لتسجيل حساب مستخدم، أو سجّل دخول المالك بالبريد المحدد وكلمة المرور التي وضعتها في Secret. حساب المالك يُنشأ تلقائياً عند أول تسجيل دخول ناجح، ويحصل على `owner` و`lifetime`. لوحة المالك من `/admin`.

## وظائف النسخة
- واجهة عربية RTL.
- إنشاء حساب وتسجيل دخول وخروج.
- جلسات آمنة في Cookie من نوع HttpOnly.
- حفظ الحسابات والجلسات في Cloudflare D1.
- صلاحيات مالك على الخادم، لا يمكن منحها من المتصفح.
- لوحة المالك: المستخدمون، الحظر، Premium، اسم الموقع، حد الرسائل، والصيانة.
- محادثة OpenAI من جهة الخادم.
- endpoint تشخيصي `/api/health` يوضح سبب عدم جاهزية D1 أو الأسرار.

## تنبيه صريح
لم يتم النشر إلى حساب Cloudflare الخاص بك من هنا، ولم يتم اختبار الموقع على حسابك. هذه الحزمة هي ملفات المشروع المصححة؛ يلزم تنفيذ الخطوات أعلاه داخل بيئة Cloudflare الخاصة بك. ميزات توليد الصور ورفع الملفات والصوت والبحث المباشر غير مفعّلة بعد. لا يحتوي هذا الملف على كلمة مرور المالك أو مفتاح OpenAI عمداً؛ تضمينهما داخل ZIP يجعل بيانات الدخول مكشوفة لأي شخص يحصل على الملف.
